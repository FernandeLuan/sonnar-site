# SONNAR — Caça Vazamentos

Site institucional responsivo da SONNAR, com foco em apresentar os serviços de inspeção técnica e facilitar o contato pelo WhatsApp.

## Stack
- React + TypeScript
- Vite
- CSS responsivo
- Lucide React

## Desenvolvimento local
```bash
npm install
npm run dev
```

## Build de produção
```bash
npm run build
npm run preview
```

## Publicação recomendada
Conecte este repositório à Vercel e use as configurações padrão do Vite:
- Build command: `npm run build`
- Output directory: `dist`
- Install command: `npm install`
